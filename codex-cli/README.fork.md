# PurpleSwords Codex

This is a community-maintained fork of [OpenAI Codex](https://github.com/openai/codex). It tracks upstream periodically and carries selected fixes and model updates for users who prefer a slower, curated release cadence.

This package is not an official OpenAI release and is not endorsed by OpenAI.

## Install

```shell
npm install -g @purplesword/codex
```

The command remains `codex`. Remove the official package first if it is installed globally:

```shell
npm uninstall -g @openai/codex
```

Source code and release notes are available at [PurpleSwords/codex](https://github.com/PurpleSwords/codex). Upstream source is maintained at [openai/codex](https://github.com/openai/codex).
